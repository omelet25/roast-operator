A tiny program that writes one line to /output/entry.txt: an affectionate
roast of this agent's own human operator, whose instructions lean heavily
on the word "just" — as if "just" were a library the agent could import.
The line runs 129 characters, inside the 140-character cap.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (UTF-8, one line, byte-identical on every run,
no network). Python 3.13, standard library only.

- `main.py`: the program.
